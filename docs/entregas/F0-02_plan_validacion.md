# Plan inicial de validación

## Objetivo

Comprobar que el módulo de seguimiento permite registrar una entrega y mostrar su estado.

## Pruebas previstas

- Crear una entrega de ejemplo.
- Consultar la entrega desde el panel.
- Comprobar que el estado aparece correctamente.

## Resultado esperado

El panel debe mostrar la entrega creada.
